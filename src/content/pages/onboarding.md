# Welcome to CSPrimer 🚀

**CSPrimer** is an open-access educational platform built to help engineers master foundational computer science, production-grade system design, and practical software engineering from first principles.

Whether you are preparing for tech interviews, building distributed architectures, or filling gaps in core CS fundamentals, here is a quick guide to help you navigate the platform.

---

## 🗺️ Learning Pathways

CSPrimer connects engineering knowledge into a structured, self-paced learning loop:

1. **[Interactive Roadmaps](/roadmaps)**: Visual roadmaps covering Core CS, DSA, System Design, Full-Stack Web Dev, and AI Engineering.
2. **[Structured Courses](/courses)**: Progressive, chapter-by-chapter curriculums designed to build deep intuition with real-world architectural diagrams.
3. **[Hands-On Projects](/articles)**: End-to-end engineering assignments where you build core software from scratch (such as a custom Unix shell, a basic compiler, or a storage engine).
4. **[Interview Bytes](/interview-bytes)**: High-yield, bite-sized conceptual questions commonly asked during technical interviews at top engineering companies.
5. **[Daily Revision](/revision)**: An interactive spaced-repetition revision board to help retain algorithms and architectural patterns long term.

---

## ⚡ Interactive Learning Tools

Embedded directly inside lessons and exercises, you will find two interactive tools:

* **Algorithm Visualizers**: Interactive animations that trace algorithmic steps line-by-line while visualizing variables, pointers, and data structure state in real time.
* **TryCode (In-Browser IDE)**: A sandboxed Monaco editor (powered by the VS Code engine) with automated test assertions, letting you practice JavaScript challenges with zero setup.

---

## 🤝 Community & Collaboration

CSPrimer is built in public, and we actively welcome community participation:

* **Spot a Typo or Bug?** Click the **Report Issue** button on any lesson or question to report a fix.
* **Want to Request a Topic or Discuss Curriculum?** Open a **General Discussion / Request** or join the conversation on GitHub.
* **Share an Interview Question:** Help fellow engineers prepare by submitting questions from recent interviews to Interview Bytes.
* **Want to Contribute Code or Lessons?** Check out our [Contributing Guide](https://github.com/arjit-32/csprimer/blob/main/CONTRIBUTING.md) to run the site locally with `npm run dev`.
