Basics of VCN and its components in Oracle Cloud Infrastructure.

A **VCN** is a customizable, private network in Oracle Cloud.

```bash
# OCI CLI Example for VCN creation
oci network vcn create --cidr-block 10.0.0.0/16 --display-name MyVCN
```
