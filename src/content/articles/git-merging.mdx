## 1. What is Merging?

Merging combines changes from one branch into another. Most commonly, developers merge completed feature branches into the `master` or `main` branch.

```bash
# Switch to the receiving branch
git checkout master

# Merge the feature branch into master
git merge experimental
```

---

## 2. Fast-Forward Merge

A **Fast-Forward Merge** occurs when master has **no new commits** since the feature branch was created. 

Because the feature branch directly contains master's commits, Git simply advances the master pointer forward to match the feature branch without creating an extra merge commit.

## 3. 3-Way Recursive Merge

A **3-Way (Recursive) Merge** occurs when both master and experimental have progressed independently with new commits.

Git finds the common ancestor commit, combines the changes from both branches, and creates a new **Merge Commit** with two parent pointers:

## 4. Handling Merge Conflicts

When both branches edit the same lines in a file, Git pauses the merge and displays conflict markers:

```bash
git status # Show conflicted files
cat file   # Inspect conflict markers
```

Conflict markers look like:
```text
<<<<<<< HEAD
// Current branch version
=======
// Incoming branch version
>>>>>>> experimental
```

To resolve:
1. Edit the file to keep the desired code and remove the marker lines (`<<<<<<<`, `=======`, `>>>>>>>`).
2. Stage the resolved file: `git add file`
3. Finalize the merge: `git commit -m "merged experimental branch into master"`

## 5. Aborting a Merge

```bash
# If a conflict occurs and you want to cancel the merge:
git merge --abort

# If you already committed the merge locally and want to undo it:
git reset --hard HEAD~1
```

## 6. Cherry-Picking: Selective Commit Merging

Cherry-picking allows you to **pick a specific commit** from one branch and apply its changes onto your current active branch without merging the entire branch.

This is especially helpful for porting urgent hotfixes to a production release branch without pulling in unready experimental features.

![Untitled](https://res.cloudinary.com/dwa6rcttw/image/upload/f_auto,q_auto,w_800/v1741778645/Untitled_5_brqziz.png)

<GitVisualizer scenario="cherry-pick" title="Cherry-Picking Commits" />

```bash
# Switch to the target branch (e.g., master)
git checkout master

# Apply a specific commit from experimental:
git cherry-pick 5892e85
```

### Advanced Cherry-Pick Operations

- **Cherry-pick multiple commits**:
  ```bash
  git cherry-pick a1b2c3 d4e5f6
  ```
- **Cherry-pick a range of commits** (applies all commits between A and B, excluding A):
  ```bash
  git cherry-pick A..B
  ```
- **Track original commit provenance** (appends `(cherry picked from commit ...)` to the commit message):
  ```bash
  git cherry-pick -x 5892e85
  ```
- **Resolve conflicts during cherry-pick**:
  ```bash
  # After resolving conflicts in files:
  git add <file>
  git cherry-pick --continue

  # Or cancel the cherry-pick cleanly:
  git cherry-pick --abort
  ```
